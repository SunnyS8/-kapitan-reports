# Kapitan Reports

Система аналитики продаж и складского учёта для бизнеса, работающего с данными из 1С.

## Стек

- **Backend:** FastAPI (Python)
- **Frontend:** Jinja2 + Bootstrap 5 + Chart.js
- **Данные:** pandas + openpyxl (Excel-файлы 1С)
- **Деплой:** Render

## Что умеет

### Отчёты по продажам
- Продажи по клиентам / товарам (сумма, кол-во, м², наценка)
- Динамика продаж по месяцам с разбивкой по категориям и топ-5 товаров
- План vs Факт (с уклонением, рекомендациями)
- Топ клиентов и товаров в разрезе номенклатуры

### Складской учёт
- Остатки на складах с сортировкой и группировкой
- Динамика по складу (приход/расход/остаток в шт и м²)
- Неликвиды (по формуле Ирины: цена × длина × ширина × рулоны)

### Финансы
- Неоплаченные счета с автоматическим расчётом пени
- Задолженность клиента по каждому менеджеру

### Контакты и ЭДО
- Реестр клиентов с историей сделок
- Незавершённые ЭДО-документы

### Фильтрация
- Глобальный выбор диапазона дат на каждой странице
- Все отчёты обновляются при выборе периода

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## Структура

```
app/
├── main.py          # Точка входа FastAPI
├── routers/
│   ├── api.py        # API-эндпоинты для отчётов
│   └── pages.py      # Маршруты страниц
├── services/
│   ├── excel_parser.py  # Парсинг Excel-файлов 1С
│   ├── report_*.py     # 12 генераторов отчётов
│   └── excel_export.py # Экспорт в Excel
├── templates/        # Jinja2-шаблоны (12+ страниц)
└── static/
    ├── style.css     # Глобальные стили
    └── inbox.js      # Логика загрузки файлов
inbox/               # Папка для выгрузок из 1С
```

## Развертывание

Проект деплоится на [Render](https://render.com) через GitHub. Файлы выгрузок из 1С загружаются в `inbox/` через веб-интерфейс или напрямую в директорию при деплое.
